# MesCourses

Nueva aplicación Android con React Native y TypeScript, que reemplazará a ShopList (.NET MAUI).

## Objetivos

- Funcionamiento completamente offline.
- Persistencia local con SQLite.
- Estado global con Zustand.
- Conservar las funcionalidades y la identidad visual de la aplicación actual.
- Arquitectura preparada para voz, IA, OCR y sincronización cloud.

## Estado

Repositorio inicial. La implementación comenzará después del análisis funcional y visual y de acordar la arquitectura.
