# Asset provenance

The app icon and Open Sans font files were copied from the user's existing ShopList MAUI project.
They preserve the reference application's visual identity.
The splash mark is a new code-drawn shopping-cart emblem in the existing blue/coral palette,
generated by `scripts/generate-splash.ps1`; it does not replace the original app icon.
The root LICENSE was supplied by the Expo template. Review original asset licensing before distribution.
